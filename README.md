# 頁間書房

一個以繁體中文記錄個人小說閱讀的靜態網站。

這裡收藏讀過、正在讀，或想分享的故事；每本書保留簡短的閱讀筆記、想留下的句子、標籤與可追溯的作品簡介來源。

## 特色

- 深紫黑與淺藍構成的午夜書房視覺
- 書名、作者、標籤與閱讀狀態搜尋
- 依類型、閱讀狀態篩選書籍
- 書籍詳情包含閱讀筆記、留頁句子與作品簡介來源
- 資料集中於本機資料庫，便於持續新增閱讀紀錄

## 專案結構

```text
├── AGENTS.md          # 專案、內容與 Git 協作規範
├── index.html         # 網站入口
├── assets/            # 授權封面或圖示
├── data/books.js      # 唯一的本機書籍資料庫
├── scripts/app.js     # 網站互動功能
└── styles/main.css    # 網站樣式
```

## 內容原則

閱讀筆記以讀者寫給讀者的角度整理；作品簡介會保留來源連結。詳細的內容、來源與協作規範請見 [AGENTS.md](AGENTS.md)。
